# TikTok Analytics Clone

Мобильная демонстрация интерфейса аналитики TikTok Studio по предоставленным скриншотам. Это независимый учебный макет, не связанный с TikTok API.

**Фотографии:** откройте раздел «⚙ Изменить фото и данные», выберите изображение и нажмите «Сохранить». Изменения хранятся локально в браузере (localStorage).

**Публикация:** Settings → Pages → Deploy from branch → main / (root).
